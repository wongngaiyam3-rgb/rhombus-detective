# 菱形探究室｜熊貓探索樂園

香港小四課堂小組探究，學生選4A–4C及第1–6組。老師入口在 teacher/，由伺服器核對密碼。

五個活動：
1. 菱形依次與一般平行四邊形、長方形、正方形比較；按觀察、量度、討論進行。
2. 四根等長棒和兩長兩短棒閉合框架。
3. 量度、複製線段與對邊延長線；梯形作平行關係的反例。
4. 自訂分類及四邊等長驗證。
5. 等腰三角形拼出菱形、直角三角形沿斜邊拼出長方形；總結由老師揭示。

點對點尺子支援拖動、點選和方向鍵，使用SVG座標及14個螢幕像素的頂點吸附範圍。兩個端點放在同一條邊的兩端後，可記錄到四邊表。1格為網頁相對單位，不是實際厘米；圖形縮放不改變讀數。

量度證據可隨小組文字／錄音一同提交。SpeechRecognition視瀏覽器支援；MediaRecorder錄音最長3分鐘、5MB，亦可選擇音訊檔案。API由雲端D1與R2保存資料，只有有效老師工作階段可列出及播放錄音。

色彩依操作區域和比較位置分配，並非依圖形種類，避免靠顏色作判斷。支援平板與投影放大。

## 同頁討論及逐步解鎖

學生的文字、語音轉文字及錄音討論在觀察頁的側欄；小屏幕在圖形下方。討論操作只重繪討論區，不替換圖形或尺子。各活動及比較組有獨立草稿。

活動1：量好A、B、D、E的四條邊，並記下三組比較的發現。
活動2：接好四根棒，操作兩個框架並記下發現。
活動3：量好一個圖形，複製四條邊，延長同一圖形兩組對邊並記下發現。
活動4：加入新卡，分類所有圖形，以四邊等長規則驗證並記下發現。
活動5：拼合兩組三角形並記下總結。

文字可先存本機，錄音提交成功亦計作發現紀錄。完成清單後按「完成並解鎖」開啟下一活動。進度與量度保存在這部裝置，依班別／組別隔開。老師自由切換。已移除仔細檢查及跨頁跳轉路徑。
