# 菱形探究室：課堂觀察與發現

獨立課堂版，入口 `classroom/index.html`。老師投影可直接開始；學生小組操作選擇 4A–4C、1–25號。

五個活動以老師提問帶領，沒有闖關、倒數或答對才能繼續的限制。圖形名稱、邊長、等長記號及最後總結預設隱藏；老師決定何時揭示。

1. 對比六種不同外形、方向及性質的四邊形；一次選兩個放大比較。
2. 逐根拼接四根等長棒與兩長兩短的棒，再拖動框架比較。棒長固定，內角限制在20–160度，避免退化及交叉。
3. 複製線段比較邊長、逐組延長對邊。顏色僅表示正在比較的對邊，不代表平行。
4. 先自訂兩組分類規則，拖曳或點選放置，再加入反例。老師可選用「四邊等長」驗證；正方形也歸入菱形。
5. 把兩個全等的等腰三角形沿底邊鏡像拼接成菱形，再換全等的不等邊三角形拼成鷂形，觀察四條外邊。最後由老師揭示名稱及規則。

每個活動有逐題顯示的提問、可收起的備課提示、投影全螢幕及討論紀錄。紀錄只保存在當前裝置，可下載文字檔，不上傳 GitHub。

純靜態HTML/CSS/JavaScript，與原來的小步子學生練習版分開。

觀察與比較已改成四組固定配對：菱形／一般平行四邊形、菱形／長方形、菱形／正方形、菱形／風箏形。每次只顯示一組兩個圖形，並有各組專用老師提問；切換組別會從第一問開始。
