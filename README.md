# 菱形小偵探

香港小學四年級的菱形小步子互動教學網站。純 HTML、CSS、JavaScript，可直接在 GitHub Pages 使用。

## 學生入口

進入活動前選擇班別 4A–4C 及學號 1–25。六個探索活動依次進行，每次一項任務，設有讀題、分層提示及可重試的練習。

1. 數四條邊
2. 複製線段比較四邊長度
3. 配對並延長兩組對邊
4. 旋轉及縮放菱形
5. 三組多選辨認與判斷理由
6. 拖動四根等長棒，探索正方形、菱形、平行四邊形的包含關係

最後有五題小挑戰。正方形依包含式定義也是菱形。框架拖動範圍避開交叉及退化圖形。

## 紀錄

學習進度以班別及學號為鍵儲存在瀏覽器 localStorage；不會上傳 GitHub 或公開。此裝置的老師頁面可查看提示、重試次數及小挑戰的首次作答，匯出 CSV，或匯入學生下載的 JSON 紀錄。沒有跨裝置即時同步。

語音由裝置的 Web Speech API 提供，優先選擇粵語或香港中文，缺少相關語音時會選其他中文語音。所有活動都有文字及點選操作，拖曳亦有按鈕、滑桿替代方式。

## 發布

在 GitHub Pages 設定選擇 `Deploy from a branch`，分支 `main`，資料夾 `/ (root)`。沒有建置或外部套件依賴。
